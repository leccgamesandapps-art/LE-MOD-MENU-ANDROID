# LE MOD MENU V1.0

Clean Android + Native floating mod menu starter  
Based on classic LGL Team structure (ndk-build) for maximum AIDE + Android Studio compatibility.

## Features
- Floating overlay menu
- Native C++ feature system
- Toggle / SeekBar / Button / Category support
- ARMv7 + ARM64
- Works on AIDE (with NDK) and Android Studio
- Ready for KittyMemory / Dobby integration

## How to open in AIDE
1. Download/clone this repo
2. Open the **app** folder in AIDE
3. Make sure you have NDK installed in AIDE (see Docs)
4. Build & Run

## Package
`com.lemodmenu`
